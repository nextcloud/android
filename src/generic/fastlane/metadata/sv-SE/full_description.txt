Den självhostade produktivitetsplattformen som ger dig full kontroll.

Funktioner:
* Enkelt, modernt gränssnitt som följer temat på din server
* Ladda upp filer till din Nextcloud-server
* Dela dem med andra
* Håll dina favoritfiler och mappar synkroniserade
* Sök i alla mappar på servern
* Ladda automatiskt upp foton och videor som tagits med enheten
* Håll dig uppdaterad med aviseringar
* Stöd för flera konton
* Säker åtkomst till dina data med fingeravtryck eller PIN-kod
* Integration med DAVx⁵ (tidigare DAVdroid) för enkel konfigurering av synkronisering av kalender och kontakter

Rapportera problem på https://github.com/nextcloud/android/issues och diskutera appen på https://help.nextcloud.com/c/clients/android

Ny på Nextcloud? Nextcloud är en privat server för synkronisering och delning av filer samt kommunikation. Det är fri programvara som du kan vara värd för själv eller betala ett företag för att driva. På så sätt behåller du kontrollen över dina foton, kalenderposter, kontakter, dokument och övriga data.

Läs mer om Nextcloud på https://nextcloud.com
